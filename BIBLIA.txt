# BLOQUE 7 — FLUJOS DE NEGOCIO

## 7.1 Flujos principales

|   | A | B |
|---|---|---|
| 1 | Flujo | Secuencia |
| 2 | **7.1 Reserva simple** | UI → `executeBookingSaga` → resolve + revalidate → lock + transaction → `createBooking` → `_persistBooking` → unlock + complete |
| 3 | **7.2 Reserva dual (gap)** | Certificar par F1/F2 → locks → create F1 → create F2 → dos filas CitasF2 mismo `pairToken` (`DUAL_F1` / `DUAL_F2`) → compensación si F2 falla |

| 5 | **7.4 Cancelación / reembolso** | Webhook Bookings cancel y/o eCom refund → `_updateCitaSafe` (`CANCELADO`) → ledger reembolso + inventario refund → compensaciones si pendiente |
| 6 | **7.5 Caja presencial** | `registerManualTransaction` → actualiza CajaActual → ledger LEDGER_V5_FISCAL → cierre Z → HistoricoCierresZ |
